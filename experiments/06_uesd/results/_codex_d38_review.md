WARNING: Losses train on padded addition positions, while evaluation only scores result positions. `generate_addition_batch` writes real targets only to `:HALF` and pads the rest with zeros, but CE/recovery/flow losses use all `SEQ_LEN` positions: [CE A](<C:/Users/devan/OneDrive/Desktop/Projects/neuro-ai-lab/experiments/06_uesd/exp_d38_basin_coupled_flow.py:172>), [CE B](<C:/Users/devan/OneDrive/Desktop/Projects/neuro-ai-lab/experiments/06_uesd/exp_d38_basin_coupled_flow.py:180>), [CE C](<C:/Users/devan/OneDrive/Desktop/Projects/neuro-ai-lab/experiments/06_uesd/exp_d38_basin_coupled_flow.py:190>), [CE D](<C:/Users/devan/OneDrive/Desktop/Projects/neuro-ai-lab/experiments/06_uesd/exp_d38_basin_coupled_flow.py:216>), [recovery](<C:/Users/devan/OneDrive/Desktop/Projects/neuro-ai-lab/experiments/06_uesd/exp_d38_basin_coupled_flow.py:233>), and [flow target embeddings](<C:/Users/devan/OneDrive/Desktop/Projects/neuro-ai-lab/experiments/06_uesd/exp_d38_basin_coupled_flow.py:156>). Evaluation correctly uses `:HALF`. This can spend half the supervised objective fitting trivial padding zeros instead of the addition result.

WARNING: Flow inference is distribution-mismatched to flow training. Training samples `z_t = (1-t)*y_embed + t*eps`, so at `t=1` the flow head sees Gaussian noise-like `z`; inference starts at `z = h.clone()` while also using `t=1` first: [training](<C:/Users/devan/OneDrive/Desktop/Projects/neuro-ai-lab/experiments/06_uesd/exp_d38_basin_coupled_flow.py:159>), [inference](<C:/Users/devan/OneDrive/Desktop/Projects/neuro-ai-lab/experiments/06_uesd/shared/model.py:254>). The sign convention itself is consistent for reverse integration toward data, but the initial state at `t=1` is not.

WARNING: Phase D recovery loss backprops through the encoder context, not just through recovery dynamics from detached `h + noise`. `h` is detached, but `ctx` is not: [recovery path](<C:/Users/devan/OneDrive/Desktop/Projects/neuro-ai-lab/experiments/06_uesd/exp_d38_basin_coupled_flow.py:229>). If the intended recovery objective is “detached h+noise -> G -> readout,” this adds unintended encoder gradients and a larger retained graph.
